# CAR CODE

منصة عربية لتشخيص أعطال السيارات وفك رموزها (OBD-II)، مع بحث برقم الهيكل (VIN) أو بالماركة والموديل والسنة، وتغطية لأهم وحدات التحكم في السيارة (ECM, TCM, ABS, SRS, BCM, وشبكة الاتصال الداخلي).

## المزايا

- تسجيل دخول وإنشاء حساب (كلمات مرور مشفّرة عبر bcrypt، جلسات JWT).
- بحث برقم الهيكل (VIN) مع فك تلقائي للماركة وسنة الصنع حسب معيار ISO 3779 / SAE J853 العام.
- بحث بالماركة/الموديل/السنة/وحدة التحكم، أو بنص/رمز العطل مباشرة.
- قاعدة بيانات لرموز أعطال قياسية (OBD-II Generic Codes) مع شرح بالعربية ودرجة الخطورة.
- سجلّ بحث خاص بكل مستخدم.
- تصميم عربي (RTL) داكن عصري، متجاوب مع الجوال والحاسوب.

## التقنيات

- Backend: Node.js + Express
- قاعدة البيانات: SQLite (عبر وحدة `node:sqlite` المدمجة في Node.js، بدون أي تبعيات native)
- المصادقة: JWT + bcryptjs
- Frontend: HTML / CSS / JavaScript بدون أي إطار عمل (Vanilla)

## التشغيل محلياً

```bash
npm install
cp .env.example .env   # ثم عدّل JWT_SECRET بقيمة عشوائية طويلة
npm start
```

الموقع يعمل افتراضياً على `http://localhost:3000`.

قاعدة البيانات تُنشأ تلقائياً في `data/carcode.db` عند أول تشغيل، وتُملأ ببيانات مرجعية عامة (رموز OBD-II قياسية، ماركات، وحدات تحكم).

## هيكل المشروع

```
server.js                  نقطة تشغيل السيرفر
src/
  db/index.js               إعداد قاعدة البيانات SQLite + البيانات المرجعية
  middleware/auth.js         التحقق من JWT
  routes/auth.js             تسجيل / دخول / خروج / معلومات المستخدم
  routes/search.js           البحث + فك VIN + سجل البحث
  utils/vin.js                فك رقم الهيكل (WMI + سنة الصنع)
public/
  index.html                 الصفحة الرئيسية
  login.html / register.html صفحات الحساب
  dashboard.html              لوحة التشخيص (محمية بتسجيل الدخول)
  css/style.css               نظام التصميم
  js/                          منطق الواجهة
```

## ملاحظة

البيانات التشخيصية المضمّنة هي بيانات مرجعية عامة (رموز OBD-II القياسية المعروفة صناعياً) لأغراض العرض التوضيحي، وليست بديلاً عن فحص فني مختص أو بيانات تشخيصية رسمية من الوكيل.
